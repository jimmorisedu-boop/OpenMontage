# OpenMontage: аудит юзабилити и органов управления

Дата: 12 августа 2026

Объект: portable desktop-оболочка OpenMontage

Метод: сценарный проход, визуальная проверка 1365×760 и 820×620, аудит IxDF по полезности, понятности, доступности, правдоподобию обратной связи и предотвращению ошибок.

## Итог

Оболочка покрывает полный цикл «проект → материалы → задача → уточнения → улучшения → план → выполнение → результат → новая версия» без выхода из одного окна. Постоянных органов управления достаточно; добавлять монтажную панель уровня NLE не нужно, потому что продукт управляется через намерение, краткие ответы и контекстные подтверждения.

Критических и высоких проблем после исправлений нет. Остаются только отложенные улучшения, которые требуют новых backend-возможностей, а не дополнительных кнопок.

## Инвентаризация управления

| Зона | Управление | Решение | Обоснование |
|---|---|---|---|
| Верхняя панель | Проекты, таймлайн, помощник | оставить | Три независимые рабочие области полностью сворачиваются и восстанавливаются. |
| Верхняя панель | Сброс расположения | оставить | Нужен как безопасный выход после ручного изменения размеров. Иконке добавлена текстовая подсказка. |
| Верхняя панель | Название, путь и стадия | оставить как информацию | Отвечают на вопросы «где я», «где файлы» и «что происходит» без лишнего клика. |
| Проекты | Новый монтаж | оставить основным | Формирует понятную модель отдельных чатов-проектов. |
| Проекты | Поиск | оставить | Уже полезен на реальных данных с 7+ проектами; не конкурирует с основным действием. |
| Меню проекта | Переименовать, открыть папку, удалить | оставить в меню | Действия нужны редко. Удаление подтверждается и остаётся восстанавливаемым. |
| Сцена | Добавить материалы | оставить основным | Главная пустая точка входа; принимает видео, звук, изображения и документы. |
| Сцена | Открыть готовый результат | оставить контекстным | Появляется только для проверенного артефакта; есть восстановление при неподдерживаемом preview. |
| Таймлайн | Сворачивание и изменение высоты | оставить | Даёт контроль площади, но не обещает ручной NLE-монтаж. Содержимое честно строится из плана и файлов. |
| Помощник | Текстовая задача | оставить основным | Единственный универсальный орган творческого управления. Enter отправляет, Shift+Enter переносит строку. |
| Помощник | Материалы | оставить рядом с вводом | Пользователь может добавить видео непосредственно из «чата», не переключая раздел. |
| Помощник | Режим выполнения | оставить | Пользователь ранее потребовал самостоятельно выбирать подтверждение, автономность или только план. |
| Уточнения | 2–3 варианта + другой ответ | оставить контекстным | Минимизирует набор текста и не заставляет угадывать формат ответа. Неактуальные карточки блокируются. |
| Улучшения | Выбор, пропустить, применить | оставить контекстным | Уточнения отделены от необязательных идей, поэтому помощник не блокирует работу лишними вопросами. |
| План | Подтвердить и запустить | оставить контекстным | Явная граница перед изменением файлов и долгой операцией. В режиме просмотра скрыт. |
| Операция | Остановить / продолжить | оставить контекстным | Нужны только во время или после прерванной операции; показывается реальный прогресс. |
| Файлы | Исходники, результаты, версии, папка | оставить | Делает место сохранения и происхождение материалов видимыми. |
| Версии | Новая версия | оставить | Безопасная альтернатива глобальному Undo для автономного монтажа. |

## Найдено и исправлено

1. **Критично — Vite-модуль не исполнялся в HTML-строке WebView2.** Сборка перепакована в обычный inline-скрипт, запускаемый после DOM; добавлена понятная аварийная карточка вместо пустого окна.
2. **Высоко — рабочая область занимала только часть высоты.** Явно закреплены строки CSS Grid; сцена, таймлайн и боковые панели теперь используют всю доступную высоту.
3. **Высоко — узкое окно сжимало три панели.** При ширине меньше 1080 px боковые панели становятся отдельными sheets с затемнением, а сцена сохраняет рабочий размер.
4. **Средне — дублировалось управление таймлайном в узком режиме.** Верхняя кнопка скрыта; остаётся один контрол на разделителе.
5. **Средне — подписи левой панели не учитывали фактическую ширину после resize.** Добавлены container queries; вторичные подписи убираются раньше основного содержания.
6. **Средне — пиктограммы верхней панели были недостаточно самоочевидны.** Добавлены `title` и доступные названия для проектов, помощника, таймлайна и сброса.
7. **Средне — случайное удаление проекта.** Используется подтверждение, запрещено удаление во время операции, проект перемещается в локальную восстанавливаемую корзину.
8. **Низко — подробный подход модели мог засорять чат.** Он остаётся свёрнутым и содержит только 2–4 пользовательских вывода, без скрытых рассуждений.
9. **Критично — живое уменьшение окна могло закрыть интерфейс.** Эффект автопрокрутки возвращал значение host-метода как React cleanup; при смене широкого layout на компактные sheets WebView2 пытался вызвать его как функцию. Эффект сделан блочным, а сценарий wide → compact закреплён проверкой.
10. **Средне — содержимое полностью свёрнутой панели оставляло тонкий визуальный хвост.** Контент теперь принудительно скрывается вместе с нулевой шириной панели и возвращается только после раскрытия.

## Недостающие возможности, которые не следует маскировать кнопками

- Восстановление проекта из корзины требует backend-операции `restore_project`; пока интерфейс честно обещает восстанавливаемость на диске, но не рисует неработающую кнопку.
- Глобальный поиск по содержимому сценариев и расшифровок потребует локального индекса; текущий поиск охватывает названия проектов.
- Перетаскивание файлов в окно можно добавить позже как второй путь. Основной native picker уже поддерживает большие видео без HTTP и без копирования бинарников.
- История точечных правок внутри одной версии должна основываться на журнале решений; обычная кнопка Undo без транзакционной модели была бы опасной.

## Проверенные критерии

- Нет выбора модели, провайдера или агента.
- Нет обязательного HTTP-сервера, CDN или сетевого runtime-запроса.
- Все основные действия имеют текстовую подпись или доступное имя.
- Опасные действия отделены и подтверждаются.
- В минимальном окне нет горизонтального скролла и взаимного наложения основных областей.
- Клавиатурные разделители сохраняют возможность resize; motion уважает reduced-motion.
- Ошибки отображаются рядом с рабочим контекстом, а не через системный `alert`.
